# 💱 Currency Converter

A real-time currency converter built with vanilla HTML, CSS, and JavaScript. Convert between 40+ world currencies using live exchange rates.

🌐 **Live demo:** [your-link.vercel.app](currency-converter-three-sigma-84.vercel.app)

## ✨ Features

- Real-time exchange rates via [Open Exchange Rates API](https://open.er-api.com)
- 40+ currencies supported
- Swap currencies with one click
- Keyboard-friendly (press Enter to convert)
- Responsive design — works on mobile and desktop
- No dependencies, no frameworks — pure vanilla JS

## 🛠️ Built with

- HTML5
- CSS3
- JavaScript (ES6+)
- Open Exchange Rates API (free tier)

## 🚀 Getting started

1. Clone the repository:
```
git clone https://github.com/IsadoraEaston/currency-converter.git
```
2. Open `index.html` in your browser — no installation needed.

Or visit the live demo directly.

## 💡 What I learned

- Fetching and parsing data from a public REST API
- Handling async/await and error states gracefully
- Cross-rate currency conversion logic (converting via USD as base)
- Building a clean, responsive UI without any framework
